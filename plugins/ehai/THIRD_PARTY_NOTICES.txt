EffectHouse AI plugin — third-party software notices
====================================================

The EffectHouse AI plugin contains, and downloads or runs, third-party software. These notices list it with its licenses:
  1. The engine: Effect House Open Source Software Notice
  2. Engine additions: libraries the Effect House engine ships that section 1 does not list
  3. Plugin runtime npm packages
  4. Node.js 22.17.0, which the plugin runtime ships (its LICENSE)
  5. First-party packages (below).

The license texts are in these files, in order (third-party-notices/ beside this file):
